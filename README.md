ts é um superset - adicional ao js onde a a genbte consegue trabalhar com linguagem estatica - trazer mais inteligencia pro nosso codigo.

typescript é uma linguagem de programação fortemente tipada que converte o código final em js.

o node não entende ts por padrão diferente de Deno, Bun e outras plataformas que executram código JS no server-side. Por isso precisamos de ts pra js.
